# Mini-Project--Using-Excel-and-Power-BI
Executed an end-to-end data analytics project transforming raw datasets into actionable insights. Cleaned and structured data in Microsoft Excel by removing duplicates, handling missing values, and standardizing formats. Built an interactive Power BI dashboard featuring KPI cards, trend visuals, and dynamic slicers to support data-driven decisions.



**Project Name:** DATA ANALYTICS GOOGLE ADs SALES DASHBOARD 

**Description:**
This project showcases an end-to-end data analytics workflow designed to transform raw, unstructured datasets into clear, actionable business intelligence. The primary objective was to establish a reliable reporting solution that cleanses operational records and presents key performance indicators through an intuitive, executive-ready visual interface.

In the initial phase, raw source files underwent thorough auditing, cleaning, and preprocessing in Microsoft Excel to ensure high data integrity prior to analysis. This process involved identifying and removing duplicate entries, resolving missing or null values, standardizing inconsistent text and date formats, and validating records using lookup functions and conditional formatting. Once the dataset was properly structured and verified, it was imported into Power BI to design and develop an interactive, multi-visual dashboard. The final dashboard features high-level KPI cards, comparative trend visuals, and categorical breakdowns engineered to uncover underlying patterns and key performance drivers. To enhance usability for stakeholders, dynamic slicers and cross-filtering capabilities were integrated, enabling users to seamlessly drill down into specific segments and timeframes.

Through this workflow, static spreadsheet data was successfully converted into a dynamic visual reporting tool, improving data accuracy and empowering faster, data-driven decision-making. Key tools and competencies applied include Microsoft Excel, Power BI, data cleaning and validation, data modeling, KPI reporting, and dashboard design.
